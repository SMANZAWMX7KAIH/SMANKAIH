PANDUAN ASET AUDIO PATRIOTIK SMANKAIH
=====================================

Struktur folder aset musik instrumental SMANKAIH:

1. Lagu 1 — Indonesia Raya
   - File target: public/audio/indonesia-raya-instrumental.mp3
   - Format: MP3 (Stereo 128kbps / 320kbps)
   - Karakter: Aransemen orkestra simfoni khidmat & megah, ciptaan Wage Rudolf Supratman (W.R. Supratman). Instrumental murni tanpa vokal/narasi.

2. Lagu 2 — Bangun Pemudi Pemuda
   - File target: public/audio/bangun-pemudi-pemuda-instrumental.mp3
   - Format: MP3 (Stereo 128kbps / 320kbps)
   - Karakter: Aransemen orkestra patriotik bersemangat, ciptaan C. Simanjuntak (Alfred Simanjuntak). Instrumental murni tanpa vokal/narasi.

STATUS FILE:

  "File audio belum dipasang di folder server: public/audio/..."
- Pemutar tidak memalsukan audio atau memutar audio kosong.
- Pengguna dapat menekan tombol "Unggah MP3 Lokal" pada panel musik di website untuk menguji lagu dari perangkat kapan saja.
